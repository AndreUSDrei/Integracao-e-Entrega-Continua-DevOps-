## 🚀 Projeto final

**Valorant Manager (VCT Transfer & Tactical Simulator)**: web app de gestão de eSports com front em React + Vite + Tailwind e API Node (Express) com SQLite.

|              |                                                                         |
| ------------ | ----------------------------------------------------------------------- |
| 🌐 Aplicação | [projetofinaldevops.vercel.app](https://projetofinaldevops.vercel.app)   |
| 💻 Código    | [ProjetoFinalDevOps](https://github.com/AndreUSDrei/ProjetoFinalDevOps) |
| ✅ Pipeline  | GitHub Actions: instala, testa, faz build e build do Docker              |
| 🐳 Contêiner | Dockerfile + Docker Compose com healthcheck                             |

O mapeamento de cada requisito do projeto para o que foi entregue está na [Aula 10](Aulas/Aula10/Aula10.md).
